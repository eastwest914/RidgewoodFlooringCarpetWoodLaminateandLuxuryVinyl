Quick Answers

Do you sell carpet as well as install it?

Yes. You can buy a carpet from us and have it installed as part of the same project.


How do I choose between laminate and luxury vinyl tile?

Laminate offers an affordable wood look, while luxury vinyl tile handles moisture and heavy use very well. We can suggest which is better for each room.


Do you install real hardwood?

Yes. We install hardwood and other wood floors for living spaces, bedrooms and hallways.
